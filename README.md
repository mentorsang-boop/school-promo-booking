# 인천산업정보학교 고교 방문 홍보 예약

인천산업정보학교가 고등학교 홍보 방문 일정을 링크 하나로 받는 예약 페이지입니다.

- **사용자**가 방문 가능한 시간을 열어 두면, **신청자**(학교 선생님)가 그 안에서 날짜와 시간을 골라 신청합니다.
- 이미 예약된 시간은 신청자 화면에서 비활성화됩니다.
- 신청은 즉시 확정되고, 확정 안내문자를 복사하거나 휴대폰 공유창으로 카카오톡에 보낼 수 있습니다.
- **사용자**(선생님)는 관리자에게 받은 가입 코드로 "계정 만들기"에서 직접 가입합니다.
- **최고 관리자**(처음 만든 관리자)는 가입 코드 변경, 비밀번호 초기화, 관리자 지정, 계정 멈춤·삭제, 학교 자료 엑셀 올리기, 전체 예약 보기를 합니다.
- **다른 관리자**는 관리 화면에서 가입 안내를 복사하고 가입한 선생님의 이름·권한·상태만 봅니다.

현재 버전: **v3.4** (변경 내역은 [CHANGELOG.md](CHANGELOG.md))

## 주소

- 실제 페이지: `https://mentorsang-boop.github.io/school-promo-booking/`
- 체험 모드: 주소 끝에 `?demo` 를 붙이면 예시 데이터로 모든 화면을 둘러볼 수 있습니다 (데이터는 그 브라우저에만 저장).
- 신청자 페이지: `.../#/r/{사용자 주소}`
- 로그인: `.../#/login` (관리자는 `.../#/login/admin` 으로 들어가면 바로 관리 화면이 열립니다)

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 틀 |
| `assets/style.css` | 디자인 (학교 남색 #2C479D 기준) |
| `assets/logo*.svg`, `assets/emblem*.svg` | 학교 로고 (원본 AI 파일에서 추출) |
| `assets/app.js` | 화면과 라우팅 |
| `assets/schools-import.js` | 방문 홍보 배정 엑셀을 학교 목록으로 바꾸는 코드 |
| `assets/data.js` | 데이터 계층 (Supabase / 체험 모드) |
| `assets/config.js` | Supabase 주소와 공개 키, 버전 |
| `supabase/schema.sql` | 테이블, 접근 규칙(RLS), DB 함수 |
| `supabase/functions/public-api` | 신청자용 서버 함수 (가능 시간 조회, 예약 저장) |
| `supabase/functions/admin-api` | 계정 관리 서버 함수 (첫 관리자 만들기, 선생님 가입, 비밀번호 초기화·삭제) |

## 처음 한 번 설정

1. **GitHub Pages 켜기**: 저장소 Settings → Pages → Source를 `GitHub Actions` 로 둡니다.
2. **첫 관리자 만들기**: 사이트의 로그인 화면을 엽니다. 관리자 계정이 하나도 없으면 "처음 관리자 계정 만들기" 화면이 나오고, 여기서 아이디와 비밀번호를 정합니다.
3. 선생님은 `.../#/signup` 에서 가입 코드를 넣고 가입합니다. 코드는 관리 화면에서 확인하고, 최고 관리자만 바꿉니다. 아이디는 서버에 `{아이디}@isg-promo.local` 형태로 저장되며 메일은 보내지 않습니다.

## 버전 규칙

`주.부` 형식으로 1.0부터 시작합니다.

- 화면 구성이나 흐름이 크게 바뀌면 **주 번호**를 올립니다 (1.x → 2.0)
- 기능이 추가되거나 바뀌면 **부 번호**를 올립니다 (1.0 → 1.1)
- 오타·버그 수정 같은 작은 고침은 세 번째 자리를 씁니다 (1.1 → 1.1.1)

버전을 올릴 때는 `assets/config.js`의 `VERSION`, `RELEASED`와 `CHANGELOG.md`를 함께 고칩니다.
